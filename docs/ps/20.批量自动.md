## 动作

### 动作面板

快捷键 `Alt`+ `F9`

### 记录动作

::: steps

1. 点击动作面板下方的创建新组按钮
2. 创建新动作，并命名
3. 结束后再点一次红色圆点

:::

## 批处理

> [!tip]
>
> 遇到大量同类性质的操作项目时，千万不要一遍又一遍辛苦操作

::: steps

1. 选择待处理的图片的文件夹位置
2. 设定用于存储处理完的图片的文件夹位置
3. 设定图片的存储类型和品质
4. 选择要使用的动作
5. 运行

:::
